# Hey, I'm Shuyang Xing 👋

I'm an Unreal Engine game developer who loves building responsive gameplay and figuring out the systems that make it work. Give me a combat mechanic, a multiplayer problem, or a tricky engine feature, and I'm happy to dig in.

I build with **Unreal Engine and C++**, with a strong interest in gameplay architecture, networked games, and developer tools. My repositories are where I turn that curiosity into playable projects and reusable ideas.

## 🛠️ Tech stack

- **Engine & language:** Unreal Engine, C++, Blueprints
- **Gameplay:** Gameplay Ability System (GAS), Gameplay Tags, AI, combat and weapon systems
- **Multiplayer:** Replication, dedicated servers, online sessions
- **UI & tools:** UMG, CommonUI, Enhanced Input, Unreal Editor extensions
- **Visual systems:** Niagara, animation, Motion Warping
